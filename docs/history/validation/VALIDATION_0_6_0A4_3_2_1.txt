Security decision
-----------------
Legacy artifact paths are now treated as untrusted metadata and must remain inside the snapshot
directory after canonical resolution. Absolute paths, path separators, drive/anchor paths and
symlink artifacts fail closed. Legacy payload bytes are SHA-256 verified during analysis and again
before migration mutation. Migration manifests contain local filesystem/entity information and are
marked LOCAL_OPERATOR_SENSITIVE_NOT_SHAREABLE.

--storage-deduplicate dry-run before any destructive migration.
