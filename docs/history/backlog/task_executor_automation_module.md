# Task Executor / Automation module: operator-authored, ordered command runbooks per firewall (Backbox-style)

status: planned · target: 

Product Owner, 2026-09-22 (with Backbox screenshots as the reference shape): an in-product applet to write and run an ordered script of commands on any chosen firewall(s). Reference model from Backbox 'Automations': (1) Dynamic fields -- title, mandatory, type, default value, variable name, needs-encryption -- substituted as %%VAR%% in commands; (2) Task commands -- ordered rows with Type internal|remote|local, the command text, timeout (s), sleep (s), results/conditions (run-if-variable with AND/OR operator), hide output, save output to file (overwrite/append, permissions, add to file repository), set status (success/fail + message), queue/order; export/import/clone of a task; (3) Task report. Governance that must shape the design before implementation: AGENTS.md network action taxonomy -- every remote command is classified (CLASS_0 read vs write) and write-class steps need the RB.x-style gate and PO approval; secrets only through the credential store (never a %%PASSWORD%% literal in a task); reuse the existing worker transport (interactive shell, exec, fetch) and job engine (admission, lease, step attempts, audit) rather than a parallel executor; task packs should be signed/distributable per COMPLIANCE_CHECK_ENGINE.md D9. Natural first slice: read-only (CLASS_0) tasks with output saved as artefacts; write-class steps as a gated second slice.

2026-09-22: contract drafted (docs/design/TASK_EXECUTOR_AUTOMATION_CONTRACT.md, DRAFT - DO NOT FREEZE). Three PO decisions block implementation: (1) authoring surface - signed packs imported through an audited route vs an in-screen editor (the latter changes the 'no command originates in the browser' invariant and needs a decision record); (2) whether a write-class slice is wanted and under which approval; (3) no local/internal steps in slice 1. Slice 1 proposed: read-only gated packs, artefact outputs, job-engine execution, CLI task-run.
