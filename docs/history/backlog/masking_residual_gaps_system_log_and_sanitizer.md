# Masking residual gaps after logmask-v3 (see note)

status: planned · target: docs/design/DEVICE_SYSTEM_LOG_PHASE_B_CONTRACT.md

2026-10-20 (open). After logmask-v3 (heuristic free-text pass, PO 2026-10-19) and the Data Sanitizer known-identity pass, four gaps remain, none measured as a leak yet: (1) a single-word hostname that is not in the estate dictionary and has no digit, dash or dot has no token shape the heuristic can catch; (2) principal formats not yet seen in real lines (only the documented user=, User '...', sshd for/from, by/for user, admin forms are covered); (3) XLSX columns holding serial-like values without a serial-named header; (4) pcap: payload is removed, but identity-shaped content outside the keyed address/name fields is not measured. Closure: measure each against a real masked sample through the aiview canary, then extend the rule set (rule-set id changes with it) or record the residual as accepted.
