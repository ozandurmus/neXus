# PAN Authentication Transport Convergence -- URGENT: older runtime path sends credentials as URL query parameters

status: done · target: production hardening / PAN transport cleanup

Corporate Copilot source audit observed divergent PAN authentication transport behavior between older runtime and newer configuration paths. Converge only in an explicit security build together with TLS trust review; do not change current behavior implicitly.

AUDITED 2026-09-09 (NXS-LOCAL-0036, audit-only, no behavior change). Findings: docs/design/PAN_AUTH_TRANSPORT_CONVERGENCE_AUDIT.md. Divergence confirmed and is URGENT, not benign: the older runtime path (panorama/panorama_runtime_runner.py::get_api_key/op_cmd/get_devices, the live --only panorama/all collection path, also reused as-is by panorama/panorama_recovery_collector.py's RB.2 device-state recovery) sends the PAN admin username, password, and every subsequent session API key as HTTPS GET URL query parameters. The newer path (configuration/panorama_config_collector.py::_keygen/api_post, used by --only pan-config/all and by panorama/preflight_collector.py) already fixed this deliberately -- POST body for credentials, X-PAN-KEY header for the session key, with an inline comment and evidence-store provenance recording the choice -- but the fix was never back-ported to the older path. RELAY_NOTE (urgent) posted for Product Owner attention per this movement's AC-3; no fix attempted here. Convergence design (AC-4) deferred: per the audit's own severity call it is superseded by the urgent flag, and per this backlog note's original instruction any eventual fix still requires an explicit dedicated security build + TLS trust review before implementation.

2026-09-13 realignment: closed as superseded. The urgent finding (an older Python path sends credentials as URL query parameters) is a defect of a runtime that is know-how only. The rule it produced -- no credential ever appears in a URL, query string or log -- is carried forward as an invariant on the UI 2.0 Palo Alto transport (ui2_pan_transport_no_credentials_in_url). PO_DECISION_RECORD_2026_09_12 section 2 (2026-09-12): all UI 2.0 feature work is Java written from scratch; the existing Python is know-how only. Backlog realignment 2026-09-13, approved by the Product Owner in session.
