# CP preflight: add `cphaprob tablestat` (CCP unique-IP table) as an extra split-brain / control-link evidence source

status: in_progress · target: OP.0b follow-on (post S8 closure); implement only after PO approval of the gate row and the check mapping

PO request 2026-09-04 (real-environment ClusterXL S8-A, operator-supplied evidence). VENDOR SEMANTIC: `cphaprob tablestat` prints the CCP 'Unique IP's Table' -- for each cluster interface, which members are currently seen exchanging CCP on it (local member rows plus peer member rows, with per-interface IP and MAC). It answers a question the approved battery cannot: `cphaprob -a if` (CP-A4) proves the LOCAL link state of each cluster interface, not that CCP traffic is actually flowing to the peer on it. Operator scenario: one cluster interface physically disconnected while its link reports UP -- `cphaprob -a if` and `cphaprob stat` still look healthy, but the peer's row for that interface disappears from tablestat; that is the precursor to a split-brain election. So tablestat is positive, per-interface, cross-member CCP reachability evidence. WHY NOT ADDED NOW: it is a NEW device command, which is a hard-stop condition of the S8 campaign (new command authority = PO gate, `OP_0B_1_COMMAND_GATE_PACKAGE.md`), and its readiness mapping is a readiness-contract decision, not a parser fix. Nothing in the approved battery changed; `cphaprob -a if` (A4) and `cphaprob -ia list` (A5) are already approved reads and both now parse the real output shapes. WHAT IMPLEMENTATION NEEDS: (1) a gate row modelled on CP-A4 -- Vendor Check Point; Action class CLASS_0_READ; Execution plane device-direct SSH, existing per-member persistent Expert shell; Shell/context Expert direct, physical/VS0; Expected calls per member 1; Concurrency/timeout/retry as CP-A4 (NO_RETRY); Session reuse yes, same session and same INTER_COMMAND_DELAY_SECONDS pacing; Read-only evidence yes (`cphaprob tablestat` is a ClusterXL monitoring command); Evidence category F (link/control health) and/or the split-brain category. (2) SAFE RETAINED FIELDS ONLY -- the raw table carries per-interface IP addresses and MAC addresses: the parser must retain NO address, NO MAC, NO interface name; only bounded counts/booleans: number of cluster interfaces observed, number on which BOTH members are seen, number on which the peer member is absent, and whether the local member is seen on every required interface (cross-referenced only by count against CP-A4's `Required interfaces:`). Structural skeleton diagnostic applies if the shape is unrecognised. (3) READINESS MAPPING (PO decision, not to be invented): candidate checks are `no_split_brain` (peer absent on a required cluster interface = CCP not exchanged = election risk) and `control_sync_link_health` (per-interface CCP reachability, stronger than link state). The classification of 'peer row absent on a required interface' -- FAIL versus INSUFFICIENT_EVIDENCE -- must be decided against the frozen 'never KNOWN_BAD from absence' law: here the absence is inside the device's own positively-reported table, which is a different thing from a read that produced nothing, but the contract must say so explicitly before the code does. (4) VSX: physical/VS0 context only unless a per-VS semantic is separately established. (5) Tests: parser fail-closed on unknown shape; value-free retained fields (no IP/MAC survives); one call per member in the same shell; battery order and S4 command authority unchanged. Until this item is implemented, the readiness contract keeps its current (weaker) control-link evidence: link state, not CCP exchange. PO APPROVAL 2026-09-09: the Product Owner approved adding the `cphaprob tablestat` gate row (modelled on CP-A4, CLASS_0_READ, one call per member in the existing Expert session, NO_RETRY, value-free retained fields only) and asked for the readiness-contract mapping to be drafted in the same movement for review -- the mapping (FAIL vs INSUFFICIENT_EVIDENCE for peer-row-absent) is proposed with reasoning against the never-KNOWN_BAD-from-absence law, not silently decided. Dispatched as relay/NXS-LOCAL-0049. 2026-09-09 D-5: HELD until the PO runs cphaprob tablestat on hardware; engineer not resumed.
