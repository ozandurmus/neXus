## Summary

Four bounded corrections surfaced by the first live S8-A ClusterXL attempt: a host-key rejection no longer enters the connect retry loop (typed HostKeyNotTrustedError at the one shared trust seam); the CP HA preflight now defaults to the same compatibility trust mode every other CP SSH caller already had, with mandatory strict enforcement deferred to production container hardening by PO decision; A3's local_role/cluster_mode are finally merged into the fields contract project_cp_preflight_facts always documented needing; and the member session became a real per-member execution context that resolves its command plan once and stops paying a device-side login/CLI initialization per read. No new device command, no mutation, no retry/fallback authority change, no readiness-semantics change.
