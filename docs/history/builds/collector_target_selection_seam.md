## Summary

Promoted OP.0d's already-validated Check Point --cp-config-targets selector into the shared utils.collection_executor.workflow_argv() argv seam (CON.2 C2-2), so the scheduler and console job runner can now request an exact target set for the cp-config workflow instead of only the direct CLI.
