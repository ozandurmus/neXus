## Summary

Implements the local-loopback Operator Console manual-endpoint enrollment flow docs/design/LOCAL_CONTROL_PLANE_RUNTIME_AND_ENROLLMENT.md §9.1 froze: a new pre-registration identity probe (utils/pre_enrollment_identity_probe.py), a CLASS 0 console job type executed directly through the runner/admission coordinator (console/registry.py, console/runner.py), a new immutable confirmation/outcome audit trail (utils/enrollment_audit.py, deliberately NOT on utils/control_plane_store.py -- that store's own contract forbids the endpoint/reference data an enrollment audit must carry), and routes (POST /api/enrollment/probe, POST /api/registry/enrollments, GET /api/registry/devices), all persisting through the one existing, unchanged DeviceRegistry.enroll path.
