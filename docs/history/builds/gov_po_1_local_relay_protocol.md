# gov_po_1_local_relay_protocol — GOV.PO.1 -- local, file-based relay protocol for same-machine PO<->engineer coordination

## Summary

New docs/design/LOCAL_RELAY_PROTOCOL.md (DRAFT) and scripts/local_relay.py (create/append/status/validate) implement an additional, git-tracked, file-based relay transport under relay/*.json for same-machine Product-Owner/engineer coordination, reusing NEXUS_AGENT_RELAY_PROTOCOL.md's five markers and GOV.SESSION.1's SESSION_START/SESSION_CLOSE report schema verbatim, with a tool-enforced next_actor turn-ownership field and a good_to_go fast path. scripts/nexus_po_tool_gate.py extended (relay/*.json Edit/Write pattern; local_relay.py status/validate in both forms, create/append interactive-only) without touching any existing GOVERNANCE_PATHS entry, RELAY_MARKERS check, or Agent-tool branch. Does not amend or supersede the GitHub-based relay protocol.
