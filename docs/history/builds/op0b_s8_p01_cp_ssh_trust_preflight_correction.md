# op0b_s8_p01_cp_ssh_trust_preflight_correction — OP.0b S8-P0.1 - CP SSH strict trust-store preflight correction

## Summary

Correction prerequisite discovered while preparing S8-A: the shared 0.6.4 strict host-key helper (utils/cp_ssh_trust.py) loaded trusted keys into Paramiko's read-only system store (load_system_host_keys) but gated on the separate writable local store (get_host_keys), so strict=True was unusable even with a correctly provisioned system/user known_hosts; the strict precondition now means 'at least one configured trusted host-key source was successfully loaded', derived through public Paramiko APIs only (explicit system known_hosts path + paramiko.HostKeys parse of the same file), with unreadable/malformed sources failing closed under distinct value-free reason tokens. All five CP SSH callers inherit the fix through the one helper; RejectPolicy, fail-before-connect and compatibility mode are unchanged; no AutoAdd/TOFU/enrollment, no new trust source or config surface, no device command or network behavior, zero device contact.
