# operator_console_read_only — Operator Console -- CON.1 read-only surface

## Summary

Implemented docs/history/phase/CON_1_OPERATOR_CONSOLE_READ_ONLY.md against the frozen contract: an authenticated loopback ASGI console (console/ package) serving the existing UI modules and report payloads live, with zero action capability, zero device contact and no vendor import. New: console/{auth,payloads,app,server}.py, templates/console.html, static/console_actions.js, main.py --console [--console-port N] (mutually exclusive maintenance-class mode, no credential), requirements-console.txt. C-D1/C-D2 (project/roadmap.json) approved 2026-09-01 per their documented recommendations and consumed as-is. utils/html_export.py gained MODULE_ORDER/compose_modules and build_report_payloads (C1-2/C1-4: the console and the exporter now call the identical payload-builder function, so a drift between them is impossible by construction). app_bootstrap.js's initialization became initializeReport(payloads) (C1-3); static mode (templates/index.html) calls it with the inline JSON constants, console mode calls it after an authenticated /api/payloads fetch.

## Risks forward

AC-8 (console/ must transitively import no checkpoint/*, panorama/*, configuration/* module) surfaced three pre-existing eager module-level imports of configuration.* reachable from utils/html_export.py -- utils/config_ui.py (align_checkpoint_management_intent, build_pan_current_configuration), utils/config_history.py (four helpers from configuration.current_config_projection), utils/crypto_posture.py (_artifact_bytes). Not introduced by this build (every other mode already pulled these in eagerly), but only closeable once console/ made the import graph a tested invariant. Fixed by moving each to a lazy import at its point of use, same DEV.3.3-established pattern as the optional-dependency preflights; behavior-preserving for every existing caller (Python caches the module on first import either way). A human interactive real-browser open on a real workstation is the cheap non-blocking follow-up that moves this build from AUTOMATED_VALIDATED to DONE, same pattern codebase_modularization (frontend) used.
