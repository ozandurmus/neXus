# gov_po_1_local_relay_watch_command — GOV.PO.1 -- bounded, read-only `watch` subcommand for the local relay

## Summary

Adds a bounded, read-only `watch` subcommand to scripts/local_relay.py so a session can wait for a relay file's next_actor to flip without manual re-checking (relay/NXS-LOCAL-0003-local-relay-watch-command.json's SESSION_START, Product Owner direction after real relay#11-#16/local-relay-protocol use surfaced this friction). Never a background daemon by construction (--timeout has a hard ceiling and --interval a hard floor), never writes to the file it watches, and never itself authorizes acting on a detected next_actor flip.
