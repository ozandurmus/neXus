# gov_po_3_orchestrator_observability — GOV.PO.3 -- orchestrator observability: streaming engineer output + watch dashboard

## Summary

Extends the already-frozen scripts/orchestrator.py (docs/design/GOV_PO_3_APPROVED_MOVEMENT_ORCHESTRATION.md section 3.4) with real-time visibility: the engineer's claude -p invocation now streams stream-json output incrementally instead of only at process exit, a new dependency-free parser derives a human-readable engineer.summary.log alongside the raw log, orchestrator status gains a last_activity field, and a new read-only `orchestrator watch` terminal dashboard polls the same status data in a loop until Ctrl-C. Backward compatible with movements dispatched before this change.
