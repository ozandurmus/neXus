# compliance_posture_foundation — Compliance Posture Foundation

## summary

Builds an evidence-backed compliance control-area view from existing CP/PAN normalized configuration UI payload with fleet/subject drilldown and roadmap-linked planned controls.

## why

Creates the VERIFY on-ramp without over-claiming certification: PASS/FINDING/UNKNOWN/NOT_APPLICABLE/PLANNED states remain bounded to observed evidence and explicit coverage limits.
