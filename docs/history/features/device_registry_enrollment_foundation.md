# device_registry_enrollment_foundation — Product Control Plane - Device Registry + manual enrollment foundation

## summary

Persistent, RuntimeRoot-resident Device Registry (opaque device_id, endpoints, vendor classification with basis, credential profile reference, enrollment source, lifecycle, tags) with CLI manual enrollment; filesystem evidence-backend concern; no device contact, no UI.

## why

The first persistent product object: stable targets to schedule, display and relate without rediscovering the estate each run. Contract: docs/design/PRODUCT_CONTROL_PLANE_ARCHITECTURE.md section 21.
