# fast_telemetry_plane — Product Control Plane - optional fast telemetry plane (SNMPv3 candidate)

## summary

Inexpensive periodic observation (availability, uptime, interface state, resource health) that marks projections changed/stale and triggers targeted authoritative collectors; never identity, configuration or eligibility authority.

## why

A future cheap signal plane behind its own security/command/OID gate; explicitly not a first-slice requirement.
