# operator_console_surface — Operator Console - read-only surface

## summary

Authenticated loopback HTTP surface serving the existing UI modules and report payloads live, with zero action capability and zero device contact.

## why

Establishes transport, authentication, CSP and the dual delivery mode (portable static report + live console) from one UI source tree, at no device risk. Contract: docs/history/phase/CON_1_OPERATOR_CONSOLE_READ_ONLY.md.
