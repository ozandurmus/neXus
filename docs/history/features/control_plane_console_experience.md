# control_plane_console_experience — Product Control Plane - first-run onboarding + device experience (console)

## summary

Welcome / Add Devices (candidates) and per-device Overview / Inventory / Configuration / Backups / HA / Jobs / Diagnostics as projections over existing payloads, in the existing CON.x console with payload parity and an action-free exported report.

## why

The product interaction model of a persistent control plane; OP.2.D's class 2 flow is expected to live on this HA tab so a second console is never built.
