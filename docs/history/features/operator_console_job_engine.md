# operator_console_job_engine — Operator Console - job engine and read-class actions

## summary

Durable job records plus a closed registry of read-class actions (re-collect an inventory plane, RB.3a attestation, report rebuild), executed through the same main() path the scheduler uses.

## why

The phase where the product becomes an operator tool rather than a report you regenerate from a terminal - with no new device command and no write. Contract: docs/history/phase/CON_2_CONSOLE_JOB_ENGINE_READ_ACTIONS.md.
