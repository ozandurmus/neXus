# crypto_agility_pqc — Cryptographic Posture, Crypto-Agility & PQC Readiness

## summary

Normalize IPsec/IKE proposal, TLS policy, certificate and platform-capability facts for Check Point and Palo Alto; evaluate against versioned rule packs for crypto-agility, known-weak algorithms and PQC readiness. Distinct from and dependent on the core Compliance Rule Engine.

## why

Turns existing configuration evidence into actionable crypto risk findings without adding new vendors or collectors. Supports NIST/PCI-DSS framework mappings and strategic PQC transition planning.
