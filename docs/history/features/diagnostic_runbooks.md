# diagnostic_runbooks — Product Control Plane - Diagnostic Runbooks (CLASS 0, closed catalog)

## summary

Bounded ordered read-only diagnostic sequences over registered targets from a closed source catalog sharing the CE.2 primitive registry; timeouts, output limits, redaction, audit.

## why

Operators run diagnostics from the product without a browser-to-shell path; every step passes the network-device command gate for this purpose.
