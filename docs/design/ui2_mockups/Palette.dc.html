Rules that keep it timeless
One accent, used for wayfinding only. Active nav, links, focus ring, primary bar fills. Never for status.
Depth from tone, not shadow. Surface → surface-2 → surface-3 steps and hairlines; no card shadows, no radial gradients, no blur.
Meaning is text first. Every chip carries its label; icons only on attention and fault; expected differences carry none.
Evidence is monospaced and timestamped. Freshness, provenance and run id are visible on every screen, not in a tooltip.
Density is a setting, not a redesign. 34px controls, 9px row padding, 13px type; a compact mode reduces spacing only.
