## New & Remaining Findings Ranked

### P0 — Must Fix Before Ship (Blocker)

#### NEW-P0-1: `ScriptRunPodSpec.LAUNCHER` closes `fd 3` *before* expanding `2> >(sed ... >&3)` — breaking `stderr` capture on every run and killing scripts writing to `stderr` with `SIGPIPE` (`EXIT_CODE_141`)
- **Location:** [ScriptRunPodSpec.java:58-60](../../ui2/worker/src/main/java/com/securityexpert/nexus/ui2/worker/scriptrunner/ScriptRunPodSpec.java#L58-L60) (introduced in `cff2d5c0` while addressing P2-12; masked in unit tests because [ScriptRunBrokerTest.java](../../ui2/worker/src/test/java/com/securityexpert/nexus/ui2/worker/scriptrunner/ScriptRunBrokerTest.java) uses `FakeKubernetes` and never executes `LAUNCHER` under `/bin/bash`).
- **Failure scenario:** `LAUNCHER` now executes:
  ```bash
  exec 3>&1
  "$@" 3>&- 2> >(sed -u -e 's/^/E|/' -e '$a\\' >&3) < /dev/null | sed -u -e 's/^/O|/' -e '$a\\'
  ```
  In GNU Bash (`redir.c` `do_redirections`), redirections on a simple command are processed strictly left-to-right, and a process-substitution redirectee (`>(...)`) is expanded when its redirection entry is reached:
  1. `3>&-` executes first in the pipeline child and closes `fd 3`.
  2. `2> >(sed ... >&3)` then forks the `sed` process substitution with `fd 3` **already closed**.
  3. The `sed` subshell immediately aborts with `/bin/bash: ...: 3: Bad file descriptor`, closing the read end of `"$@"`'s `fd 2` (`stderr`) pipe.
  4. All script `stderr` output is dropped, and any process writing to `stderr` after the pipe closes — including `.jar` scripts and `/app/nexus-cli` invocations (which emit `NOTE: Picked up JDK_JAVA_OPTIONS: ...` to `stderr` on startup because [ScriptRunPodSpec.java:494](../../ui2/worker/src/main/java/com/securityexpert/nexus/ui2/worker/scriptrunner/ScriptRunPodSpec.java#L494) sets `JDK_JAVA_OPTIONS`), Python tracebacks/logging, or `echo ... >&2` — receives `SIGPIPE` (`rc = 141`, recorded as `FAILURE` / `EXIT_CODE_141`).
- **Fix:** Place `3>&-` **after** `2> >(... >&3)` (and close `fd 3` in the parent shell before `wait`):
  ```bash
  exec 3>&1
  "$@" 2> >(sed -u -e 's/^/E|/' -e '$a\\' >&3) 3>&- < /dev/null | sed -u -e 's/^/O|/' -e '$a\\'
  rc=${PIPESTATUS[0]}
  exec 3>&-
  wait
  exit "$rc"
  ```
  Add a unit test in `ScriptRunBrokerTest` that executes `ScriptRunPodSpec.LAUNCHER` with `/bin/bash` and verifies `O|` stdout, `E|` stderr, exit code `0`, and `3: Bad file descriptor` when the child attempts `>&3`.
