# Backup line implementation audit — 2026-09-15

## Status

**DRAFT -- AUDIT, NOT AUTHORITY.** This document records repository findings. It decides nothing, freezes nothing, and does not assess restore, which remains disabled.

## Scope and method

This audit checks every `BK-*`, `AL-*`, `DV-*`, `OR-*`, `RC-*`, `MS-*`, and `BW-*` clause in the three 2026-09-14 backup decision records, plus C7 §8's numbered backup obligations. C7 §8 criteria 7–10 are restore-only and excluded; criterion 4 is checked only for the backup-manifest half. That produces 55 evaluated clauses.

Each clause has exactly one verdict:

- `IMPLEMENTED_AND_TESTED`: the producer reaches its consumer and a named test holds the join.
- `IMPLEMENTED_UNTESTED`: source carries the behavior, but no test asserts the stated join or one required edge.
- `NOT_IMPLEMENTED`: a required producer, consumer, guard, persistence field, or join is absent.
- `NOT_EVALUABLE`: repository evidence cannot decide the clause, normally because it requires a live device or deployment fact.

The order is by consequence, not contract order. Tier 1 can permit an unauthorized or unaudited action, disclose prohibited data, or report unsafe success. Tier 2 can lose custody, integrity, retention, or recovery evidence. Tier 3 affects bounded operational correctness without creating the Tier-1 failure directly. Tier 4 leaves a declared feature or validation step incomplete.

The three most consequential findings are:

1. **BK-14 / OR-1:** a filesystem-relative path is used as `artefact_id` and returned by the HTTP listing. The no-path rule is violated through an identifier even though the explicit path column is omitted.
2. **BK-12 / BW-4:** allowlist, role, and reason checks stop at HTTP admission. The asynchronous job does not persist or freshly re-check them, and the reason never reaches execution or audit.
3. **BW-3 / C7-2:** the executor collapses the gated multi-step backup sequence into one aggregate step-attempt row, so audit evidence cannot establish which class-0/class-1 substeps actually ran.

The clauses not evaluable from repository evidence are BK-4 and BK-7 (pilot-device behavior), AL-2 and AL-4 (deployment/custody location), and MS-4 (future management-server measurement). No automated or fixture evidence was treated as a substitute for those facts.
